# Research Fixtures

This directory contains fixtures and public/synthetic test material allowed by the relevant research protocol.

## Boundary rules

- fixtures are not substitutes for a private evaluator oracle or hidden independent outcomes;
- do not reconstruct expected private labels/paths from public fixtures;
- keep benchmark role/exposure semantics explicit;
- scripted/synthetic fixtures may validate structure, plumbing and failure handling but do not by themselves establish real task quality or production capability;
- version fixture changes that materially affect an experiment and preregister/re-evaluate when required.

Check the relevant frozen experiment contract before using a fixture in candidate development or evaluation.
