# Research Experiments

This directory contains preregistrations, experiment definitions, eligibility/activation artifacts and other prospective experimental contracts.

## Rules

- define decision question, comparison, metrics, thresholds and stop/failure semantics before outcome-dependent execution whenever feasible;
- version material changes instead of silently rewriting a frozen experiment definition;
- distinguish infrastructure amendments from candidate/semantic changes;
- exact experiment semantics come from the relevant frozen/preregistered artifact and source pins;
- an experiment file does not itself authorize execution: check `docs/CURRENT-PROJECT-STATUS.md` and the corresponding authorization/gate.

Historical experiments remain available for provenance even when consumed, failed or superseded.
