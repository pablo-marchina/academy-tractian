## 3. Classification semantics

- `REUSE_UNCHANGED`: implementation/behavior can be used without changing its semantics for ADR-018/019.
- `REUSE_WITH_BOUNDED_ADAPTER`: proven logic remains valid but requires a narrowly scoped v2 adapter/schema around changed Cloudflare inputs or outputs.
- `INCOMPATIBLE_HISTORICAL_ASSUMPTION`: the frozen implementation encodes ADR-008/009/OpenAI/Gemini identity and must not be executed as-is for ADR-018/019.
- `MISSING_MATERIAL_CAPABILITY`: ADR-018 requires behavior that ADR-010/011 never implemented.

### ADR-010 conclusion

The old executor **must not be invoked in live mode as-is**. The minimum correct future implementation is a **prospective v2 executor/bundle/result layer** that reuses the proven provider-neutral logic and the unchanged public population, while replacing only the old frozen input/client identity and resource-accounting pieces.

It is unnecessary and undesirable to redesign P01-P08, B1, ADR-007 provenance, latency statistics, repeat stability, 32-attempt ordering or `NO_SELECTION` from scratch.

### ADR-011 conclusion

## 6. Minimum demonstrated implementation gaps

Only the following new capabilities are justified by this audit:

1. **Current-scope frozen bundle/plan adapter**
   - pin ADR-018 design v2 and exact population SHA;
   - pin ADR-019 Cloudflare client blob;
   - materialize only the two eligible Cloudflare live candidates;
   - preserve the 32-attempt order but freeze a new plan SHA.

2. **Provider-comparison result v2 resource fields**
   - exact usage completeness;
   - observed neurons per attempt/candidate/packet;
   - actual cash-cost status required to remain USD 0;
   - Cloudflare-specific M9 fields;
   - H8/H9/H10 status/failure codes.

3. **Cloudflare M8/resource guard**
   - frozen GLM and Nemotron neuron rates;
   - 8000 prompt / 512 completion observed ceilings;
   - `max_packet_neurons = 7937.522688`;
   - missing usage fails closed;
   - before every next attempt, verify cumulative observed neurons plus frozen worst-case remaining usage cannot exceed the available free allocation.

4. **Cloudflare fixed failure probes**
   - same one-invocation, zero-retry/fallback, sanitized ADR-007 checks;
   - execute provider-free against both exact ADR-019 model configurations.

5. **Cloudflare live client factory**
   - one explicit API token + account ID;
   - one shared generic one-shot stdlib transport;
   - instantiate exactly the two ADR-019 model IDs;
   - no environment lookup or credential probing.

6. **Current authorization/custody marker v2**
   - one durable canonical root;
   - pin exact live authorization, ADR-018, ADR-019, v2 plan/executor/client identities;
   - preserve fixed internal `run/`, exclusive create, no reset/replay and sanitized evidence.

7. **Pre-live zero-cost evidence gate**
   - before attempt 1, separately frozen evidence must establish Workers Free, no Paid/prepaid Gateway path, and >=9000 free neurons remaining for the current UTC day without consuming inference;
   - the execution code must refuse to start without that evidence.

No other executor/custody redesign is justified by the inspected evidence.
