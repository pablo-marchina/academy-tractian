# Documentation Archive

`docs/archive/` is for superseded **non-binding narrative/planning documentation** that is still useful for historical context.

Do not move a file here merely because it is old. Frozen artifacts, canonical results, source-pinned research files and material needed to reproduce consumed/failed experiments should remain at stable paths.

Before archiving a document, verify that:

- it is not the current canonical status/plan/governance document;
- no frozen artifact depends on its path/content;
- it is not required as a canonical result/closure or ADR;
- all current navigation links point to the replacement;
- the archived filename makes its historical date/version clear.

Git history is the primary record of edits to canonical living documents; the archive should not become a second competing current documentation tree.
